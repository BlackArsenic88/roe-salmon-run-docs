# 🐟 Roe: Salmon Run

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
![Expo](https://img.shields.io/badge/Expo-v51.0.0-000000.svg?logo=expo&logoColor=white)
![React Native](https://img.shields.io/badge/React_Native-v0.74.5-61DAFB.svg?logo=react&logoColor=black)
![License](https://img.shields.io/badge/license-Private-red.svg)

**Roe: Salmon Run** is a retro 8-bit vertical arcade runner developed with React Native and Expo. Players control Roe the Salmon as it swims upstream against turbulent river currents, dodging bear hazards with sharp claws extending from the riverbanks.

## 🕹️ Controls

| Action | Control |
| --- | --- |
| **Swim Left / Upstream** | Tap Left side of screen |
| **Swim Right / Upstream** | Tap Right side of screen |
| **Pause / Resume** | Tap top-center Pause button |
| **Share Score** | Tap Share button on Game Over screen |
